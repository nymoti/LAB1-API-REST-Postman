# LAB 1 : Conception et test d'une API REST avec HTTP et Postman

Tests d'une API REST avec Postman, sur l'API publique [dummyjson](https://dummyjson.com).

## Contenu

- `postman/` : la collection et l'environnement à importer dans Postman
- `rapport/rapport.md` : le rapport, à exporter en PDF

## Utilisation

1. Dans Postman, cliquer sur **Import** et sélectionner les deux fichiers du dossier `postman/`.
2. Choisir l'environnement **Demo API Env** en haut à droite.
3. Lancer la collection **LAB1 - Gestion Produits REST** avec **Run collection**.
